# Federal Gold

Source of https://federalgold.org — a static, single-page site for Federal Gold
Kuyumculuk (Kapalıçarşı, Şemdinli, Van).

- `index.html` — the whole site (inline CSS and JS, TR/EN)
- `data/products.json` — showcase (vitrin) products
- `assets/` — images
- Hosted on Cloudflare Workers static assets.
